# Screenshots

Visual proof of everything this repo builds, for anyone reviewing the submission
who shouldn't have to stand up BigQuery access, Dagster, or Streamlit locally
just to see that it works. Referenced from the main `README.md`.

Each subfolder has its own short README saying exactly what to capture and a
suggested filename. Drop the actual `.png`/`.jpg` files alongside them.

| Folder | What it's proving |
|---|---|
| `dagster/` | The asset graph, the daily schedule, a green run |
| `miro/` | The data infrastructure flow diagram |
| `dbt-docs/` | The model DAG and column-level documentation, generated not hand-written |
| `dashboard/` | The Streamlit app, one shot per tab |
| `bigquery/` | Raw vs. analytics dataset separation, in the warehouse itself |
